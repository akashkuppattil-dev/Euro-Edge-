================================================================================
PROJECT SUMMARY: EURO EDGE TECHNICAL SERVICES L.L.C.
================================================================================

1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
- Company Name: Euro Edge Technical Services L.L.C.
- Domain & Geography: Technical contracting, MEP (Mechanical, Electrical, Plumbing),
  HVAC installation & maintenance, civil maintenance, interior fit-outs, and facility
  management across Dubai and the United Arab Emirates (UAE).
- Platform Purpose: A modern, high-converting corporate website and interactive
  client portal designed for B2B and B2C clients in Dubai. It showcases services,
  project portfolio case studies, provides instant service quote estimation, displays
  Annual Maintenance Contract (AMC) packages, handles career applications, and captures
  leads through WhatsApp and direct contact forms.


2. TECHNOLOGY STACK
--------------------------------------------------------------------------------
- Core Framework: Next.js 16.1.6 (App Router architecture)
- Library: React 19.2.4 & TypeScript 5.7.3
- Styling & Design System:
  * Tailwind CSS v4 with PostCSS
  * Modern typography via Google Fonts (Inter, Playfair Display, Outfit, Plus Jakarta Sans)
  * CSS animations via tw-animate-css
- UI Components & Primitives:
  * Radix UI (Dialog, Accordion, Popover, Select, Tabs, Tooltip, Navigation Menu, etc.)
  * Lucide React (Icon library)
  * Embla Carousel (Service pillars & featured service carousels)
  * Sonner (Toast notifications) & Vaul (Drawer dialogs)
  * Recharts (Data visualization / statistics)
- Form Handling & Validation: React Hook Form integrated with Zod validation schemas
- Analytics & SEO: Vercel Analytics (@vercel/analytics), JSON-LD schema markup (JsonLd),
  and dynamic metadata / sitemap generation.

4. CORE FEATURES & USER JOURNEYS
--------------------------------------------------------------------------------
1. Dynamic Service Architecture (/services/[slug]):
   - Driven by a centralized TypeScript data dictionary (lib/services-data.ts).
   - Services include: Electrical Works, HVAC & AC Maintenance, Plumbing, MEP
     Contracting, Civil Maintenance, Fit-Outs, and Facility Management.
   - Each service page includes rich technical descriptions, key features, real-world
     applications, DEWA regulatory compliance info, and related services.

2. Interactive Instant Quote Estimator (quote-estimator.tsx):
   - Allows potential clients to select property type, service scope, and size to
     calculate estimated costs with a direct call-to-action to book.

3. Projects & Case Studies Portfolio (/projects & projects-portfolio.tsx):
   - Filterable showcase by categories: Residential, Commercial, Facility Management,
     Hospitality, Industrial.
   - Shows project scopes, timelines, technical highlights, and high-resolution visuals.

4. Annual Maintenance Contract (AMC) Module (amc-packages.tsx):
   - Pre-packaged maintenance solutions for Dubai villas, commercial properties, and buildings.

5. High-Conversion Contact & Sticky CTAs:
   - Floating WhatsApp & quick-dial buttons optimized for the UAE market.
   - Modals for requesting quotes on specific services.

6. Technical SEO & Compliance:
   - Full JSON-LD structured data for Google Search rich snippets (LocalBusiness, MEP contractor in Dubai).
   - Fast static generation with Next.js App Router for optimal Core Web Vitals.


5. KEY SCRIPTS & COMMANDS
--------------------------------------------------------------------------------
- Start Development Server: npm run dev  (Runs locally on http://localhost:3000)
- Production Build:        npm run build
- Run Production Server:   npm run start
- Linter:                  npm run lint
